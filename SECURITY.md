# Security policy

The first published version is a release candidate. Stable production qualification
is tracked in `docs/release-verification-v1.0.0-rc.1.md`.

Report suspected vulnerabilities privately to mail@uttam.dev. Include the affected
package version, a synthetic reproduction, and the expected impact. Do not include
production exception data, credentials, or customer information. Please avoid
public issues for undisclosed vulnerabilities.

Keep Laravel, Telescope, PHP and this package patched. Monitoring sanitizes its own
imported evidence; Telescope source storage has its own privacy configuration.
